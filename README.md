# ОКБ скринингтік белгілерін математикалық талдау

Бастапқы NeuroCheck дизайны сақталған ғылыми жоба сайты. Қазақ тілі әдепкі тіл; EN / РУС ауыстырғыштары, тақырып түстері және анимациялар сақталған.

## Ғылыми шекаралар

- 60 анкета: жеке жауаптар әлі тексерілмеген.
- 21/60 = 35% және шартты Уилсон интервалы [24.2; 47.6]% — алдын ала мәлімет.
- 8/15 есебі — жеке оқу мысалы.
- Байес параметрлері модельдік немесе сыртқы жарияланымнан алынған; осы іріктемеде валидацияланбаған.
- Жеті мәндік қатар — иллюстрация; AR(1) нүктелік болжамы мен демонстрациялық 25% қате ережесі көрсетілген.
- C++ — прототип, Telegram-бот — тұжырымдама. Скрининг диагноз емес.

Есептер, алғышарттар және дереккөздер: [research-notes.md](docs/research-notes.md).

## Іске қосу және тексеру

Node.js 20+ және Python 3. Қосымша пакет қажет емес.

```sh
npm test
npm run check
npm run build
npm run dev
```

Жергілікті бет: http://127.0.0.1:4173. `dist/` — дайын статикалық жинақ. Негізгі файлдар түбірде де сақталады, сондықтан GitHub Pages бұрынғыдай түбірден жариялай алады. Доменге арналған `CNAME` сақталған; Vercel конфигурациясы `dist/` жинағын жариялайды.

Бұрынғы қосымша сервис беттері және пайдаланылмайтын сыртқы AI endpoint жойылған. Сайт сыртқы API-ге немесе дерек жинау сервисіне сұрау жібермейді.
