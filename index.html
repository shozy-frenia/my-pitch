01 · Зерттеу сұрағы

Скринингтік белгілерді қалай бағалауға болады?

Жоба жауап үлестерін, шартты ықтималдықтарды және болжам қатесін қарастырады. Бұл — әртүрлі математикалық шамалар; олардың ешқайсысы өздігінен медициналық диагноз қоймайды.

Зерттеу міндеттері

  • 01Топты сипаттау. Алдын ала 21/60 жиілігін анкетаның бастапқы жауаптарымен салыстыру.
  • 02Белгісіздікті бағалау. Берілген жиілік үшін шартты Уилсон интервалын есептеу.
  • 03Prior рөлін түсіндіру. Байес арқылы сезімталдық пен оң нәтиженің болжамдық құнын ажырату.
  • 04Болжамды тексеру. Оқу қатарының тексеру мәнін Стьюдент интервалымен және AR(1) 25% қате ережесімен салыстыру.
02 · Әдіс

Төрт классикалық құрал, әрқайсысы бір іске.

Әр әдіс бөлек сұраққа жауап береді. C++ үзіндісі — есептеу прототипі; валидацияланған диагностикалық жүйе емес.

M1Байес формуласы

Сезімталдық, ерекшелік және базалық жиілік берілгенде оң скринингті кейінгі ықтималдыққа айналдырады. Дәл осы базалық жиілік мәселесін жасырмай, көрінетін етеді.

M2Уилсон интервалы

Уилсон бинарлық жауап үлесінің белгісіздігін бағалайды. Алдын ала 21/60 үшін 95% интервал [24.2; 47.6]%; жиілік пен сұраққа сәйкестігі дұрыс болуы шарт. Ол іріктеу ығысуын түземейді.

M3Стьюденттің прогностикалық интервалы

Орта мәнге емес, бір жаңа бақылауға арналған интервал. Мысалда n = 6, df = 5, t = 2.5706. Бақылаулар тәуелсіз, бірдей қалыпты үлестірілген деп алынады; қысқа қатарда бұл тексерілмеген.

M4AR(1) моделі

Алғашқы алты мәннің бес көршілес жұбы 5.9286 нүктелік болжамын береді. Абсолютті қате шартты 25% ережемен салыстырылады; бұл ықтималдық интервалы емес.

Дерек деңгейлерін ажырату

60 анкета топты сипаттайды. Жеті мәндік қатар — қатысушыдан алынғаны расталмаған сандық иллюстрация. Сауалнама уақыттық модельді валидацияламайды.

Түсіндіру шекарасы

Модельдік PPV — диагноз, сауалнамада өлшенген нәтиже немесе тексерілген жолдау ережесі емес. Ол prior мен тест параметрлеріне тәуелді.

05 · Шектеулер

Зерттеу шектеулері.

Алдын ала жиіліктер, модель параметрлері және оқу есептері әртүрлі дәлел деңгейіне жатады. Олар бөлек қарастырылады.

  • ✕Диагноз емес. Анкета жауабы да, болжам ауытқуы да диагноз қоймайды.
  • ✕Валидацияланған шкала емес. Se, Sp және 25% динамикалық шек кодта бекітілген сценарий параметрлері, клиникалық эталонға қарсы өлшенген шамалар емес.
  • ✕Жалпыланбайды. Жеке жауаптар тексерілмеген. 60 анкета көлемінің өзі репрезентативтілікті немесе клиникалық жарамдылықты дәлелдемейді.
  • ✕Маманды алмастырмайды. Прототип ем ұсынбайды және маманға жіберу туралы шешім қабылдамайды.
  • ✕Прототип кезеңі. C++ — демонстрациялық үзінді; Telegram-бот — тұжырымдама, іске қосылған қорғалған клиникалық сервис емес.
  • ✓Ол не. Формулалар, оқу мәндері, алғышарттар және есептеу тексерістері берілген қолданбалы математика ғылыми жобасы.

// 0 < prior, se, sp < 1
double ppv(double prior, double se, double sp) {
    const double tp = se * prior;
    return tp / (tp + (1 - sp) * (1 - prior));
}
